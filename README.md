# Local Utilities

Une application web avec une multitude d'outils divers.

## À propos

Cette application web est un projet personnel visant à expérimenter avec les PWA et Services Workers pour créer une application web utilisable hors ligne. Elle regroupe plusieurs outils pour mon usage personnel.

## Technologies utilisées

- Vue.js 3
- Composition API
- Tailwind CSS
